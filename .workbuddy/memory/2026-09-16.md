## 修复上架驳回：description 含 "Obsidian"（v0.18.2）

**问题**：community.obsidian.md 提交报 `Plugin description must not include the word "Obsidian".`（`manifest.json:6`）。审核原文：*"The word 'Obsidian' in the description is redundant. It is implied by the context of the plugin directory."*

**改动**
- `manifest.json`：description `…directly in Obsidian.` → `…directly in your vault.`（136 字符，句号结尾）；`version` → `0.18.2`。
- `package.json` / `versions.json`：同步 0.18.2（versions.json 追加 `"0.18.2": "1.4.0"`）。
- `.github/scripts/check-version.mjs`：新增 description 四条**断言（error 级）**——含 `obsidian`、以 `This plugin…` 开头、>250 字符、结尾不是 `.?!` 或 `)`；同时给 name 补 `Obsi` 开头 / `dian` 结尾两条 warning。另打印 description 原文与字符数，本地方便肉眼复核。
- `README.md`：发布示例 tag 0.18.1 → 0.18.2。
- `tsc -noEmit -skipLibCheck` + `esbuild --production` 均通过（main.js 实际不含版本号，此改动不影响产物）。

**验证**
- `node .github/scripts/check-version.mjs` → exit 0，0 提示。
- 故意回归（`.workbuddy/tmp/regress-check.js`，把 4 种文案分别喂给 checker）：原始被驳回文案 / `This plugin…` 开头 / 结尾无标点 → 全部 exit 1 且命中红线；合法文案 → exit 0。**新断言确实会拦，不是假绿。**

**结论 / 未做**
