## 清掉 `obsidianmd/no-static-styles-assignment` 全部 34 处

**触发**：用户贴来审核侧 eslint 报错，34 处 `element.style.X = "字面量"`，分布在 6 个文件（DrawPanel 3 / DrawioView 8 / FloatingPanel 3 / FormatPanel 10 / PageBar 7 / ViewMenu 3）。

**改法（按性质分两类）**
- **静态状态 → 复用已有 `.drawio-hidden` 工具类**（`display: none !important`）：customSizeRow、ctxMenuEl、toolwin、pagebar dropEl / menuEl、viewmenu。⚠️ `.drawio-pagebar-drop` 样式表里原本写着 `display: none`，必须先**删掉那行**再换类，否则摘掉工具类它仍然是隐藏的。类切换一律用原生 `classList`（见下）。
- **JS 算出来的值 → CSS 自定义属性**，新建 `src/cssVars.ts`（`setCssVars` / `clearCssVars`，内部 `style.setProperty` / `removeProperty`）：
  - 页面视图宽高 `--drawio-page-w/h`（`.drawio-page-block` 里 `width/height: var(...)`；退出时摘变量 → 回落到 `.drawio-graph-container` 的 `100%`，所以 4 条内联写法全没了）
  - 网格 `--drawio-grid-image/size/pos`（关网格 = 摘声明，回落 `none/auto/0 0`，不再写 `= "none"` / `= ""`）
  - 页签拖拽 `--drawio-tab-dx`（消费点挂在既有的 `.is-dragging` 上，`transform: translateX(var(--drawio-tab-dx, 0px))`）
- **FormatPanel**：`colorField` 的透明 `<input type=color>` 6 条静态声明搬进新规则 `.drawio-fmt-color input`；`toggleBtn` 的 bold/italic/underline 改成 `.drawio-fmt-body .drawio-fmt-tbtn.drawio-fmt-tbtn-*`（**特异性故意与 `.active` 同为 (0,3,0) 且写在它之后**，否则选中态 `font-weight: 600` 会盖掉 bold）；`paintSwatch` 把两个分支合并成「先算变量再赋一次」。
- **`setCssProps`/`setCssStyles` 不能用**：`minAppVersion` 是 1.4.0，这两个 API 1.13 才有，且 d.ts 里没有 `@since`（`no-unsupported-api` 查不出来）。

**顺手发现（本轮刻意不动）**：`toggleBtn` 的第 4 个调用点传 `"strike"`，但原代码只处理 bold/italic/underline —— 即「S」按钮从没有字形预览样式。按「保持行为不变」原则原样保留（新类名也没给它建规则），等用户决定是否补 `.drawio-fmt-tbtn-strike`。
