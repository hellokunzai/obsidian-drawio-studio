# Drawio Studio

[English](README.md) · **简体中文**

Drawio Studio 让你直接在 Obsidian 中编辑和查看 [draw.io](https://www.draw.io/) 图表，完全离线、无外部服务、无网络请求。它使用与 draw.io 相同的 `.drawio` 文件格式，所以你的图表始终保持可移植性，在任何支持 draw.io 的地方都能打开。

## 功能特性

- **原生 `.drawio` 编辑** —— 在可编辑画布中打开 `.drawio` 文件；使用通用或复合后缀的文件（`.xml`、`x.drawio.svg`）可在文件列表中右键 **以流程图打开**。
- **内置 mxGraph 引擎** —— 与 draw.io 同源的开源渲染引擎，直接打包进插件，无需联网、无遥测。
- **丰富的形状面板** —— 四类：便笺本（收藏夹）、通用、杂项、高级；支持按名称搜索、分类折叠 / 展开；内置流程图、UML、网络图、容器、图标等图形。
- **拖拽创建** —— 从面板拖拽形状到画布，或双击画布空白处快速创建。
- **完整工具栏** —— 撤销 / 重做、放大 / 缩小、适应视图、重置缩放、删除选中、清空画布、导出 SVG、保存。
- **格式面板**（选中图形时显示）：填充配色预设（6 页共 48 组）、线条与线型（实线 / 虚线 / 点线）、不透明度、效果（阴影、圆角、草图、玻璃）、字体 / 背景 / 边框颜色、渐变、自动换行、格式化文本、间距、对齐、书写方向、层级（置顶 / 置底 / 上移 / 下移）、大小与位置、旋转、翻转、对齐到网格、组合 / 解组、锁定 / 解锁、复制样式、设为默认样式。
- **绘图面板**（未选中图形时显示）：页面视图、网格大小与颜色、背景、阴影、连接箭头 / 连接点、对齐参考线、页面尺寸预设 + 自定义 + 朝向、自适应颜色、编辑图表数据、清除默认风格。
- **视图菜单** —— 切换形状面板、格式栏、标尺、查找 / 替换、图层、标签、缩略图（大纲）。
- **查找 / 替换** —— 在整张图表中检索图形文字，支持区分大小写与全部替换。
- **图层** —— 把图形归类到命名图层，可显示 / 隐藏、锁定 / 解锁。
- **标签** —— 给图形打标签，并在整张图表范围内管理标签。
- **缩略图（大纲）** —— 一瞥掌握大型图表的全貌。
- **多页图表** —— 新增、插入、复制、重命名、删除、排序页面（兼容 draw.io 多页模型）。
- **便笺本** —— 从右键菜单把常用图形收藏起来，随时拖回画布复用。
- **自适应颜色** —— 让图形配色随当前主题自动调整。
- **自动保存** —— 停止编辑后自动把改动写回文件（可调防抖延迟）。
- **主题适配** —— 跟随 Obsidian 亮色 / 暗色主题。
- **SVG 导出** —— 把当前图表导出为 SVG 文件。

## 安装

1. 从最新 [Release](https://github.com/hellokunzai/obsidian-drawio-studio/releases) 下载 `main.js`、`manifest.json`、`styles.css` 三个文件。
2. 放入 `<笔记库>/.obsidian/plugins/drawio-studio/` 目录。
3. 在 Obsidian 设置 → 社区插件中启用 **Drawio Studio**。

## 使用

- 运行命令 **新建图表**，或在文件列表中右键文件 / 文件夹选 **新建流程图** 来创建图表。
- 双击 `.drawio` 文件（或对 `.xml` / `x.drawio.svg` 选 **以流程图打开**）即可在画布中打开。
- 从右侧形状面板拖拽形状到画布。
- 点击工具栏图标进行缩放、导出、保存等操作。

## 界面一览

### 工具栏

位于图表视图顶部。按钮包括：撤销、重做、放大、缩小、适应视图、重置缩放、删除选中、清空画布、导出 SVG、保存。

### 形状面板

在左侧。分类（便笺本、通用、杂项、高级）点击标题即可折叠 / 展开。搜索框可按名称过滤形状。拖拽形状到画布，或双击空白画布快速创建。

### 格式面板（选中图形）

在右侧。标签页：**样式**、**文本**、**排列**。

- **样式** —— 填充预设、线条、线型、不透明度、效果、各种颜色、渐变。
- **文本** —— 字体颜色、自动换行、格式化文本、间距、书写方向。
- **排列** —— 对齐、层级、大小 / 位置、旋转、翻转、对齐到网格、组合 / 解组、锁定 / 解锁、删除。

### 绘图面板（未选中图形）

在右侧。标签页：**绘图**、**样式**。

- **绘图** —— 页面视图、网格、背景、阴影、选项（连接箭头 / 连接点 / 参考线）、页面尺寸。
- **样式** —— 自适应颜色、默认风格、编辑图表数据。

### 视图菜单

工具栏最左侧按钮打开菜单，可切换：形状面板、格式栏、标尺、查找 / 替换、图层、标签、缩略图。

### 浮动工具窗

- **查找 / 替换** —— 查找图形文字、区分大小写、替换 / 全部替换。
- **图层** —— 新建 / 排序 / 删除图层，显示 / 隐藏，锁定 / 解锁。
- **标签** —— 给选区或整张图表添加 / 移除标签。
- **缩略图** —— 整张图表的缩略导航图。

### 多页

画布底部的页面栏支持新建 / 插入 / 复制 / 重命名 / 删除 / 排序页面，兼容 draw.io 的多页模型。

### 右键菜单

在图形上右键可剪切、复制、创建副本、粘贴、锁定 / 解锁、设为默认样式、调整层级、编辑样式 / 数据 / 链接 / 连接点，或添加到便笺本。

## 设置

打开 **设置 → 社区插件 → Drawio Studio**：

| 设置项 | 说明 |
| --- | --- |
| 自动保存 | 停止编辑后自动把改动写回文件。关闭后只能用工具栏的保存按钮手动保存，切换或关闭标签页也不会写盘。 |
| 自动保存延迟（毫秒） | 最后一次改动后等待多久写盘，取值 200 - 60000 毫秒。 |
| 显示网格 | 在画布上绘制背景网格，同时开启拖动时的网格吸附。 |
| 默认连线样式 | 新绘制连接线时使用的走线方式：**正交折线** 或 **直线**。已有连线保留各自样式。 |

## 技术说明

- 基于打包进插件的 mxGraph 渲染引擎（draw.io 的底层库），因此 **无需联网**。
- mxGraph 出厂时给 `mxStylesheetCodec` / `mxDefaultToolbarCodec` 打开了 `allowEval`，会让手工构造的 `.drawio` 文件借样式表执行 JS。插件在引擎加载后立即把两者关掉，因此打开不可信文件也无法通过样式表执行脚本。
- `isDesktopOnly: true`，仅在桌面端可用。
- 无网络请求、无遥测、无广告。

## 与其它 draw.io 插件的兼容性

`.drawio` 这个扩展名同一时刻只能被一个插件占用：Obsidian 的视图注册表会拒绝重复注册，注册失败的那个插件会直接加载失败。所以本插件 **无法与已上架的 Drawio（`drawio-editor`，作者 doge-liang）或更早的 Diagrams（`drawio-obsidian`）同时启用**——请只保留其中一个。

## 开发与发版

### 本地构建

```bash
npm install
node node_modules/typescript/bin/tsc -noEmit -skipLibCheck   # 类型检查
npm run build                                                # 生产构建，产出 main.js
```

`main.js` 未被 git 跟踪，构建产物由 GitHub Actions 现场生成，无需手动提交。

### 发布正式版

1. 同步升版本号：`manifest.json` 与 `package.json` 改成同一版本，并在 `versions.json` 追加 `<版本>: <minAppVersion>` 条目。
2. 提交并推送这次版本号改动。
3. 打 tag 并推送（**tag 名就是版本号，不加 `v` 前缀**）：

   ```bash
   git tag 0.18.3
   git push origin 0.18.3
   ```

CI 会构建后创建 GitHub Release，附 `main.js` / `manifest.json` / `styles.css` 三件套。也可以在 GitHub 仓库的 **Actions → Release → Run workflow** 里填版本号手动发版，由 workflow 自己打 tag。

### 预发布（BRAT）

在 commit message 里带关键字即可：

- `[beta]` → 生成 `<版本>-beta.<序号>` 预发布版
- `[rc]` → 生成 `<版本>-rc.<序号>` 预发布版，并清理本轮遗留的 beta 预发布

普通 commit 不会触发发布。

### 自动化检查

- **CI**：push 到 main 或提 PR 时跑类型检查 + 构建，确保改动可编译。
- **Version Check**：校验 `manifest.json` / `package.json` / `versions.json` 三处版本号一致，并顺带检查 manifest 元数据合规（`id` / `name` / `description` / `author`）。

两个检查都可在本地复现：`node .github/scripts/check-version.mjs`。
